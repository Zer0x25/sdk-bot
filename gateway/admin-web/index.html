📲 Conexión y pairing

● Sin sesión de WhatsApp activa
Esperando QR…
El QR generado vale 1 minuto: escanéalo con WhatsApp > Dispositivos vinculados > Vincular dispositivo antes de que expire. Si el gateway está apagado, primero usa "Lanzar gateway".
Recibirás un código de enlace de 8 dígitos en WhatsApp (Dispositivos vinculados > Vincular con número de teléfono). Si el gateway está apagado, se lanza solo con el primer intento.
● Conectado como —
El bot ya está vinculado a WhatsApp. Para vincular otro número tendrás que resetear la sesión.
Resetear: borra la sesión guardada y reinicia el gateway. Después tendrás que volver a vincular con QR o con número.
