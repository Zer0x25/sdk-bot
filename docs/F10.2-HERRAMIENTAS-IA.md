# F10.2 — Contratos y ejecución segura de herramientas IA

**Estado:** implementado y verificado localmente el 2026-10-22. No publicado.

## Alcance

El contrato `AssistantToolRequest` acepta una sola herramienta de solo lectura:
`conversation.search_messages`. Su consulta admite 1–256 caracteres y pide de uno a
cinco resultados. El Gateway comprueba de nuevo `conversations:read`, liga la
búsqueda al mismo hilo y al snapshot recibido, devuelve solo referencias verificables
y fragmentos acotados, y aplica un límite de tres segundos.

Brain puede proponer esa solicitud en la etapa de planificación. Gateway valida la
lista permitida, ejecuta el acceso SQLite y devuelve los resultados para una única
etapa final. Brain no obtiene acceso a SQLite, adaptadores, canales, URLs arbitrarias
ni shell. No hay herramientas de escritura: una solicitud de envío o de otro efecto
se rechaza antes de ejecutar cualquier acción.

Cada ejecución registra en SQLite un hash de solicitud, un hash de resultado cuando
termina, actor, conversación, herramienta, efecto, estado, clave idempotente y
contador de intentos. No se almacenan la consulta ni el contenido de los mensajes.
Los registros expiran a los 180 días. La nueva migración es schema v14; el checkpoint
de recuperación y la puerta offline de restore comparan también cantidad y digest de
esta auditoría. La salida de restore muestra el contador y el código de diferencia,
no las huellas.

La bandeja divulga que puede buscar hasta cinco fragmentos anteriores del mismo
hilo. Las citas pueden recorrer páginas de historial anteriores para enfocar el
mensaje fuente, con un máximo de 50 páginas por navegación.

## Verificación

Se probaron autorización propia de la herramienta, límite de tiempo, petición de
solo lectura de Brain, rechazo de escritura, consulta acotada, snapshot obsoleto,
referencias vinculadas al hilo, idempotencia, expiración a 180 días, copia de backup,
checkpoint de restore y navegación a citas anteriores. Las pruebas usan SQLite
temporal y respuestas falsas; no conectan proveedores ni canales reales.

- `npm run check` (raíz): contratos 19/19, generación sincronizada y typecheck.
- `cd apps/gateway && npm run check`: lint/typecheck, panel 42/42, build Vite,
  integración del build 1/1 y Gateway 356/356.
- `cd apps/brain && ../../brain/venv/bin/ruff check . && ../../brain/venv/bin/python
  -m pytest tests/ -q`: Ruff limpio y 34/34 tests.
- `git diff --check`: limpio. Sin proveedores reales ni canales iniciados.

## Límites

No se habilitan integraciones externas ni acciones con efectos. Una búsqueda más
amplia requiere una nueva herramienta con contrato, permiso, límites, auditoría y
revisión propios. La evaluación sintética transversal continúa en F10.4.
