# F7.4 — Asistente

## Resultado

La navegación React incorpora `/inbox/assistant` para listar y administrar los
perfiles Markdown del brain. Las sesiones con `admin:write` pueden abrir el
archivo editable, crear perfiles, importar `.md`/`.txt`, guardar, recargar la lista,
ver el prompt compilado, eliminar perfiles no predeterminados y exportar el borrador
actual desde el navegador.

La pantalla conserva los cambios sin guardar al cancelar el cambio de perfil y al
cancelar la navegación. También advierte al cerrar o recargar la pestaña. Un borrador
nuevo con una clave ya existente pide confirmación antes de sobrescribir; eliminar
un perfil requiere confirmación y `default` no ofrece eliminación. Los archivos
importados y borradores se limitan a 900.000 bytes.

Las sesiones sin `admin:write` consultan únicamente `/api/v1/profiles`, que entrega
claves y nombres. No cargan contenido, prompt compilado ni llaman las rutas legacy
de lectura/escritura de perfiles. La frontera `admin:write` que protege `/api/*`
legacy se cerró en F7.3 y sigue siendo la autoridad de backend.

## Verificación

- `cd gateway && npm run panel:typecheck` — pasa.
- `cd gateway && npm exec -- vitest run --config panel/web/vite.config.mts panel/web/src/features/assistant/AssistantPage.test.tsx` — 9 pruebas pasan con API simulada.
- `cd gateway && npm run check` — pasa ESLint, typecheck Gateway/React, 30 pruebas React, build Vite, montaje bajo `/inbox` y 320 pruebas Gateway.

Las pruebas cubren aislamiento de lectura, carga de archivos, confirmación al cambiar
de perfil y navegar, guardado aceptado y rechazado, sobrescritura, importación,
exportación de texto sin guardar, prompt compilado, recarga y eliminación. No se
conectó un brain live ni se modificaron perfiles del entorno.

## Límites

- Importar/guardar delega al validador actual del brain, que exige `## Personalidad`
  con contenido y `## Reglas` con al menos una viñeta. Los rechazos conservan el
  borrador local para corregirlo.
- La página React reemplaza la pestaña Perfiles para el recorrido nuevo; el panel
  legacy permanece disponible solo para administradores hasta cerrar F7 y el
  inventario de paridad.
- Esta unidad no publica perfiles a canales, no envía mensajes y no inicia llamadas
  a proveedores externos de IA.
