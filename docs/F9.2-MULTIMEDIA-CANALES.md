# F9.2 — Multimedia y mutaciones por canal

**Estado:** completa, 2026-10-22.

## Alcance

- WhatsApp y Telegram archivan los binarios de audio, imágenes, video y documentos
  que el adaptador puede descargar durante una entrada live. Los límites de
  archivo, cuota, permisos, autorización y retención son los definidos por F9.1.
- La captura se mantiene después de admitir el mensaje en SQLite. Si el proveedor
  no entrega el medio, la descarga falla, excede el límite o se satura la cola,
  queda `availability: failed`; no se conserva una URL del proveedor como acceso.
- Las citas guardan `replyToId` cuando el mensaje citado existe en la misma
  conversación. Si no existe o ya venció, guardan solo una vista previa de hasta
  512 puntos de código.
- Las ediciones observadas actualizan el mensaje existente, generan
  `message.updated` e incrementan `contextVersion`, para que un resultado de IA
  calculado con el contenido anterior no se considere actual.
- Las revocaciones WhatsApp observadas redactan el contenido y marcan el blob
  para borrado. Un evento posterior no restaura una revocación ya archivada.

## Límites de los proveedores

- WhatsApp utiliza los eventos de Baileys para ediciones y revocaciones. Las
  actualizaciones de recibo no se convierten en evidencia de entrega o lectura.
  La limpieza de chat `{ jid, all: true }` se ignora porque no identifica los
  mensajes afectados.
- Telegram consume `message` y `edited_message` del Bot API, además de
  `reply_to_message`. El Bot API usado aquí no aporta una notificación general
  de borrado para mensajes ordinarios ni recibos de lectura/entrega; esos estados
  no se simulan. Los updates que no pertenecen a la captura admitida solo avanzan
  el cursor durable.
- Las descargas cubren entradas nuevas live. El historial/backfill no vuelve a
  descargar medios antiguos. La conversación propia/admin de WhatsApp permanece
  excluida del archivo. Telegram continúa como canal administrativo según la
  decisión del proyecto; su ruta legacy tampoco se prueba como atención al
  cliente en F9.2.
