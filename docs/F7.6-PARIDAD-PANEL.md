# F7.6 — Inventario de paridad del panel

## Rutas y acceso

El panel React vive bajo `/inbox` y se sirve cuando
`PANEL_CONVERSATIONS_UI_ENABLED` está activo. La ruta `/` todavía sirve el panel
administrativo legacy. Con OAuth activo, API y archivos legacy requieren `admin:write`;
el panel nuevo conserva la sesión v1 y sus grants. No se cambia el punto de entrada
ni se elimina ninguna ruta en esta unidad.

## Inventario

| Función del panel anterior | Estado en React | Ubicación o límite actual |
|---|---|---|
| Dashboard: uptime, Node, RAM, estado WA/TG, Brain y último error | Migrado en parte | Sistema muestra proceso, memoria, canales, Brain, bot y almacenamiento. El número/LID de admin, uptime detallado de Brain, conteos de contactos por estado, métricas completas de broadcasts, edad del elemento más antiguo de la cola y estadísticas de DB/memoria del Brain siguen visibles solo en el Dashboard legacy. |
| Ejecutar comandos administrativos y pausar/reanudar el bot | Migrado | Sistema llama el mismo `commandHandler`; el terminal no ejecuta shell. |
| Iniciar Brain | Migrado | Acción de Brain en Sistema. |
| Vincular WhatsApp con QR/código, renovar QR, ver estado y borrar sesión | Migrado | Canales conserva el único dueño del transporte; borrar sesión está en Sistema. |
| Reset limpio de fábrica | Migrado | Sistema conserva aviso, 10 s de lectura, palabra `BORRAR-TODO` por 60 s y envío único. Los perfiles Markdown sobreviven. |
| Vincular/desconectar Telegram y ver estado | Migrado | Canales configura token reingresado y Chat ID; no revela el token guardado. |
| Envío de mensaje para probar Telegram y descubrir Chat ID | Omitido deliberadamente de React | Telegram queda como canal administrativo; se puede configurar un Chat ID manualmente. El botón y endpoint de prueba permanecen en el panel legacy mientras `/` siga disponible; esta auditoría no los ejecutó. |
| Buscar contactos por nombre, teléfono o LID y cambiar estado/perfil | Migrado con límite | Contactos edita permisos/perfil por conversación archivada y busca por nombre/canal. Búsqueda por identificadores y contactos legacy sin conversación siguen disponibles solo en el panel antiguo. |
| Crear, editar, importar/exportar, recargar y borrar perfiles; ver prompt compilado | Migrado | Asistente conserva las operaciones con `admin:write`, confirmación de borradores y protección de `default`. |
| Logs Gateway/Brain, filtro, pausa, limpieza del archivo activo | Migrado | Logs de Sistema mantienen stream acotado, filtro, pausa/reconexión y confirmación; los archivos rotados se conservan. |
| Campañas/broadcasts | Sin página dedicada antes ni ahora | El dashboard legacy muestra métricas y los comandos siguen disponibles en el manejador administrativo. Sistema muestra pendientes; no se inventa un flujo de campaña incompleto. |
| Bandeja, historial archivado, takeover, respuesta humana y retorno seguro a IA | Nuevo flujo React | Bandeja no tenía equivalente en el panel legacy; se implementa sobre API v1. |
| Resumen de actividad archivada | Nuevo flujo React | Resumen por periodo y canal, respaldado por la API v1; no sustituye conteos no archivados del Dashboard legacy. |

## Decisión de retiro

El inventario no demuestra paridad suficiente para retirar `/`: siguen existiendo
detalles operativos y casos de contacto que la UI nueva no presenta. La página
legacy permanece disponible para administradores; no se cambian datos, permisos,
OAuth ni rutas de operación. El envío de prueba de Telegram queda fuera de React,
según el uso administrativo acordado, y no se ejecutó en esta verificación.

Antes de retirar el panel anterior hay que migrar o eliminar de forma explícita:

1. Los detalles de diagnóstico listados arriba o su decisión documentada de retiro.
2. La búsqueda por teléfono/LID y el acceso a contactos antiguos sin conversación.
3. El botón y endpoint legacy de prueba Telegram, si se retira formalmente.
4. La visibilidad de métricas completas de broadcast/cola o su decisión de retiro.

## Verificación

- Se compararon `gateway/panel/public/index.html`, `js/app.js` y los módulos
  Dashboard, WhatsApp, Telegram, Contactos, Perfiles y Logs con las rutas React y
  sus APIs.
- La suite Gateway que pasó al cerrar F7.5 incluye la prueba de frontera OAuth:
  lectura v1 no habilita la UI/API legacy y `admin:write` sí. Esta unidad documental
  no añade ni repite pruebas runtime.
- No se abrió el panel en un navegador, no se cambió configuración y no se llamó
  al proveedor Telegram.
