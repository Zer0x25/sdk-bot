# F4.2 — Lectura HTTP real de la bandeja

Actualización: 2026-10-20. La UI de `gateway/panel/web` ya consulta la lectura
autenticada del panel OAuth; envío y control humano quedan para F5.

## Resultado

- Lista de cuentas y conversaciones con búsqueda por contacto, filtros de canal,
  no leídas y abiertas, selección en URL y paginación con cursor.
- Detalle contextual con canal/estado, automatización, ciclo, no leídos y cobertura.
  El hilo pagina los mensajes más recientes y hacia atrás, conserva el ancla de
  scroll y presenta autoría, estados de entrega y marcadores multimedia.
- Al visualizar mensajes entrantes se persiste el cursor local monotónico por
  `inboundSeq`; no se emiten recibos remotos. Los cursores vencidos reinician desde
  la primera página. BUG-063 queda cerrado en `BACKLOG.md`.
