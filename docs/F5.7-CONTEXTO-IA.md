# F5.7 — Contexto explícito y reanudación IA

Actualización: 2026-10-20. Estado: implementada y validada en Linux con Node
24.19.0 y Python 3.12.14.

## Resultado

- El gateway entrega a Brain un lote explícito con `generation_id`, conversación,
  `context_version`, ancla de archivo y mensajes anteriores clasificados. El lote
  se arma desde SQLite: entran mensajes de cliente y salidas humanas/IA con ACK
  aceptado; las salidas propias sin intent aceptado no se presentan como diálogo.
- Brain expone `/generate-reply`. Usa solo el contexto recibido, mantiene la
  respuesta durable por `generation_id` para replay idempotente y no llama
  `append_exchange` para una respuesta aún no enviada. Una clave repetida con otro
  cuerpo/version falla con 409. `/invalidate-generation` deja un tombstone para
  impedir que un trabajo cancelado se recupere después.
- Los IDs archivados del lote viajan con el debounce y la cola. El `generation_id`
  se deriva de conversación, versión de contexto y IDs de origen; las claves de
  outbox derivan de generación/globo. Un reinicio puede pedir el borrador guardado
  y el outbox evita repetir un globo ya aceptado.
- La migración SQLite v8→v9 añade una secuencia monotónica de ingreso y una
  frontera por conversación. `/limpiar memoria` mueve la frontera e incrementa la
  versión de contexto, sin borrar mensajes del archivo. La IA futura excluye el
  tramo anterior aunque sus fechas de proveedor sean posteriores o desordenadas.
- El despacho valida el estado de control justo antes de la llamada al proveedor;
  los trabajos obsoletos invalidan su generación. La pausa global drena trabajos
  IA y deja activa la captura y la ruta de envío humano.
- Release solo acepta el comportamiento `future_only` en esta fase. La API devuelve
  409 `PENDING_RESUME_NOT_AVAILABLE` para `process_pending`; la selección de
  mensajes pendientes está prevista en F6.

## Verificación

- Brain: `ruff check` y `pytest apps/brain/tests/` cubren contexto explícito, replay,
  conflicto de clave, invalidación y persistencia del borrador sin añadirlo al
  historial legacy.
- Gateway: `tests/aiContext.test.js`, `tests/controlJobs.test.js`,
  `tests/outboundIntent.test.js`, `tests/messageQueue.test.js`,
  `tests/controlService.test.js` y pruebas de captura/migración verifican autoría,
  límite `/limpiar`, reanudación de cola, rechazo obsoleto y compatibilidad de
  archivos anteriores.
- La prueba integrada con transporte falso se registra en
  [F5.8](F5.8-ACEPTACION-INTEGRADA.md).

## Límites registrados

- BUG-073: una salida propia de WhatsApp cuyo ACK tarde más de 500 ms puede pasar
  por la ruta de salida humana antes de que el outbox publique el ID aceptado.
- BUG-074: Brain conserva las respuestas idempotentes sin política de retención.
- No se usaron cuentas reales ni se migraron archivos runtime.
