# F4.3 — actualización en vivo de la bandeja

Actualización: 2026-10-20. Integra el stream SSE autenticado /api/v1/events en
la bandeja de gateway/panel/web.

## Resultado

- Al abrir el stream, el panel actualiza la lista, las cuentas y el detalle de las
  conversaciones afectadas. Las invalidaciones se agrupan para absorber ráfagas.
- El hilo seleccionado pide solo mensajes recientes; mantiene las páginas antiguas
  en caché, elimina duplicados por ID y conserva el ancla cuando se reciben mensajes
  mientras el operador lee hacia arriba.
- Si el replay contiene más mensajes que una página, la lectura sigue los cursores
  hacia atrás hasta solapar el snapshot reciente que ya estaba cargado. El botón de
  novedades desplaza al final y limpia el contador.
- Al vencer el cursor o cambiar el epoch, se reinician las páginas y se carga un
  snapshot nuevo. El estado de conexión distingue conectado y reconectando.

BUG-070 registra el hueco que podía aparecer si una desconexión acumulaba más de 50
mensajes; F4.3 lo cierra. Otra regresión verifica que un evento recibido mientras
hay una petición en curso provoca un segundo refresco y no se pierde.
