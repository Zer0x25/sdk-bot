# F5.8 — Aceptación integrada Fase 5

Actualización: 2026-10-20. Validación sintética con SQLite temporal, proveedores
IA falsos y transportes falsos; no se conectaron cuentas ni archivos runtime.

## Escenarios verificados

| Escenario | Evidencia |
|---|---|
| Trabajo obsoleto antes de llamar al Brain y cancelación entre globos | `gateway/tests/controlJobs.test.js`: no inicia request con snapshot viejo; tras takeover simulado no envía globos posteriores e invalida el `generation_id`. |
| Takeover mientras la llamada al proveedor ya empezó | `gateway/tests/f58Acceptance.test.js`: control queda `taking_control`; un timeout queda `delivery_unknown`; al drenar se confirma humano y se registra el intent incierto. |
| Operaciones repetidas, versiones viejas y reinicio en human | `gateway/tests/controlService.test.js`: idempotency key, CAS, operación pendiente/reanudada y release conservan control/perfil. La API rechaza `process_pending` con 409; `future_only` es la conducta de F5. |
| Aceptación del proveedor y replay del envío | `gateway/tests/outboundIntent.test.js`: claim concurrente produce una llamada, accepted replay no vuelve al proveedor y timeout/reinicio queda `delivery_unknown`. |
| Salida propia desde teléfono y eco de envío local | `gateway/tests/whatsappCapture.test.js`: eco aceptado no activa handoff; salida desconocida sí; los ecos aceptados quedan deduplicados. BUG-073 cubre la carrera del ACK lento. |
| Humano → IA con contexto y globo aceptado | `gateway/tests/f58Acceptance.test.js`: dos mensajes humanos llegan a `/generate-reply`, la generación se repite con el mismo ID y el transporte envía una sola vez; el siguiente contexto incluye la respuesta IA aceptada. |
| Contexto limpiado sin borrar archivo | `gateway/tests/aiContext.test.js` y `gateway/tests/controlService.test.js`: frontera y versión avanzan, el archivo conserva las filas y futuras consultas excluyen el tramo previo. |
| Pausa global con salida humana autorizada | `gateway/tests/outboundIntent.test.js`: el path humano continúa disponible durante la pausa global. La captura se ejecuta antes del consumidor de automatización en las pruebas de adapters. |

## Resultado de ejecución

`gateway npm run check` incluye ESLint, TypeScript, panel, build y suite Node.
Brain se verifica con Ruff y `pytest brain/tests/`. Cualquier fallo encontrado al
integrar la migración se corrigió en los fixtures para que modelen archivos v4–v7
válidos; la secuencia de migración v8→v9 quedó probada desde esos esquemas.

No se declara aceptación de proveedor/canal real, Windows, Termux ni de un deploy.
BUG-073 y BUG-074 quedan abiertos en [BACKLOG.md](BACKLOG.md), con aceptación y
fase límite.
